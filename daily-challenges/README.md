# Week 7 Daily Challenges

Each challenge is a separate practice exercise. The main To-Do List remains the assessed mini-project.

## Day 1 — Theme Persistence
The main project includes a light/dark theme toggle. The selected theme is saved in localStorage and restored on page load.

## Day 2 — Recent Searches
Build a search field that stores the five most recent searches in localStorage. Show the history and allow a user to select an earlier search.

## Day 3 — Form Auto-Save
Build a form that saves its fields to sessionStorage every five seconds and restores them after refresh. Clear saved values after successful submission.

## Day 4 — Refactor Challenge
Refactor an older JavaScript project: use meaningful names, extract repeated code into functions, add error handling and remove duplicated logic.

## Day 5 — Code Review
Review the Week 6 Weather Dashboard. Check error handling, organization, readability and loading states. Record at least five improvements in a file named `weather-review.md`.

## Submission note
Complete and commit each challenge as you work. Do not claim the Weather Dashboard review or a classmate's peer review is complete until you have actually done it.
